## What's new

### "?" button now explains how saving works

The "?" icon in the top bar was a dead button. It now opens a **HelpModal** with a 5-step walkthrough of VisaPrep's no-account save model:

1. **No account needed** — no passwords or sign-ups
2. **Save your progress** — "Sign in" generates a link encoding country, step, profile, and all document statuses
3. **Keep the link** — copy it or email it to yourself; that link is your save file
4. **Restore anywhere** — open the link on any device to resume exactly where you left off
5. **Your files stay private** — uploaded documents live only on your device, never in the link or on a server

This clarifies the URL-hash save model that already powers the "Sign in" dialog.
