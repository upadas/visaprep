## What's new

### Core checklist app
First working release of VisaPrep — a Canada tourist visa document checklist built as a static single-page app.

### Features shipped

**Wizard view**
- Step-by-step document checklist with keyboard navigation (← →)
- Per-document status controls: Todo / In Progress / Done
- File upload with drag-and-drop per document (DropZone)
- Sub-checks per document (e.g. passport validity, blank pages)
- Tips panel per document with country-specific guidance

**Board (kanban) view**
- Drag-and-drop cards across Todo / In Progress / Done columns
- Powered by @dnd-kit/core — accessible, pointer-and-keyboard drag
- Click any card to jump to that step in Wizard view

**Progress bar**
- Completion fraction (done / total documents)
- Toggle between Wizard and Board views
- PDF export button (stub) and Save button (stub)

**Applicant profile rail**
- Purpose selector: Tourism / Business / Study / Transit
- Travel party: Solo / Couple / Family
- Prior visa history: First time / Visited before / Been refused

**Country selector**
- Dropdown in TopBar — Canada, USA, Schengen (3 initial entries)
- Country meta displayed in page header: fee, processing time, flag

**Persistence**
- All progress auto-saved to `localStorage` under keys `vp-status`, `vp-files`, `vp-tweaks`
- Survives page reload

**Tweaks panel**
- Theme toggle: Light / Dark / System
- Density toggle: Compact / Comfortable / Spacious
