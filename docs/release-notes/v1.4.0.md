## What's new

### Documents page is now country-aware

Previously the Documents page showed a static, hardcoded list of 8 generic document cards and referenced "40 supported countries" (the app has 5). It now reads the **selected country** and renders the real per-country document list from `getDocsForCountry(country)`:

- Heading reflects the country (flag + name)
- Each card shows the document title, a **Required / Optional** badge, summary, accepted file types, and a "What to prepare" list
- Switching countries in the top bar updates the page instantly
- Read-only reference layout — no checkboxes, no upload (that's the checklist's job)

### "Read guide →" actually works now

The guide cards' "Read guide →" button was a dead button. It now opens a **GuideModal** — a reading overlay with section-by-section slider navigation:

- ← Back / Next → buttons move between sections
- Section counter (e.g. "2 / 4")
- "Done" on the final section closes the modal
- Click outside or ✕ to close
- Each guide ends with an **Official source** section linking to the real government portal

### Country-scoped guides

The Guides page now shows only the guides for the selected country. **15 guides** total (3 per country):

| Country | Guides |
|---------|--------|
| Canada | IMM 5257 · Proof of funds · Biometrics |
| USA | DS-160 · Proof of funds · Interview & biometrics |
| UK | Online VAF · Proof of funds · UKVCAS biometrics |
| India | e-Tourist Visa · Proof of funds · Photo & scan specs |
| Schengen | Annex I form · Funds & insurance · Biometrics |

Content is derived from the app's curated per-country data and links to official sources (IRCC, U.S. State Dept, UK Gov, Government of India, European Commission). Every guide carries a "rules change — always confirm on the official site" disclaimer.

### Key implementation notes

- Both pages read `country` via `useStore((s) => s.country)` — reactive to the TopBar country selector
- `GuideModal` reuses the `.modal-overlay` / `.modal` CSS classes shared with `ConfirmDialog` and `SaveModal`
- `GUIDES` is keyed by country with a `canada` fallback; each guide is `{ id, title, blurb, sections[] }` where the last section carries an official-source `link`
- DocumentsPage renders `doc.checks[].text` as a plain "what to prepare" list (no `ok` checkboxes — this is reference, not checklist)
