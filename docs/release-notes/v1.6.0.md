## What's new

### Real PDF checklist export

The "⤓ PDF" button generated a fake toast. It now produces a **real, downloadable PDF** of your visa checklist, client-side (no server):

- **Header** — country, visa type, fee, and processing time
- **Applicant summary** — passport country, purpose, length of stay, travel party, prior visa history
- **Progress** — "X of Y documents ready"
- **Document list** — every document with a Required/Optional tag and its current status (To do / In progress / Done / Skipped)
- **Embedded thumbnails** — uploaded photo/image documents are embedded directly into the PDF; PDF uploads are noted by filename
- **Disclaimer** — reminds you to confirm requirements on the official government site

The PDF button stays gated (disabled until all required documents are marked Done), so the export always represents a complete checklist.

### Hover preview of uploaded documents

In the wizard, uploaded files now have richer interaction:
- **Image uploads** — hover the thumbnail to see an enlarged preview (up to 220×280px) without leaving the page
- **PDF uploads** — click the "PDF" icon to open the document in a new tab

### "Save my progress" button now works

The progress-bar "Save my progress" button was a dead stub (toast only). It now opens the same Save dialog as "Sign in" — copy or email your restore link.

### Key implementation notes

- `generatePdf.js` splits into `buildChecklistPdf(data)` (pure — returns the jsPDF doc, unit-testable) and `downloadChecklistPdf(data)` (triggers the browser download). Tests exercise the builder and never call `.save()`.
- Image embedding via `doc.addImage(dataURL, fmt, …)` is wrapped in try/catch so a malformed image can't break the whole document.
- **Code-split**: jsPDF is loaded via dynamic `import('./lib/generatePdf')` inside the PDF click handler. It (and its `html2canvas`/`dompurify` deps) bundle into a separate ~130 kB-gzip chunk that only downloads when a user actually exports — the main bundle stays at ~97 kB gzip.
- FileCard reads `file.dataURL` directly from the store for previews — no IndexedDB round-trip needed.
