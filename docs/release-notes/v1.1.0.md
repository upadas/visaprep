## What's new

### 40-country support
The country dropdown now covers 40 curated visa destinations with real data:

Canada · USA · Schengen · UK · Australia · Japan · South Korea · UAE · Singapore · New Zealand · China · Thailand · Malaysia · Indonesia · India · Brazil · Mexico · Turkey · Egypt · Morocco · South Africa · Vietnam · Philippines · Sri Lanka · Nepal · Kenya · Tanzania · Qatar · Saudi Arabia · Oman · Jordan · Georgia · Armenia · Kazakhstan · Azerbaijan · Bahrain · Maldives · Rwanda · Ethiopia · Cambodia

Each entry includes: flag emoji, visa type name, fee (local currency), processing time, currency code, eVisa availability.

### Dynamic per-country checklists
Switching countries now updates the entire document checklist — form names, required documents, fund thresholds, and biometrics requirements all reflect the destination:

- **Form names** — IMM 5257 (Canada), DS-160 (USA), VAF (UK), Schengen application form, etc.
- **Funds** — amounts and currency adapt per country (CAD for Canada, GBP for UK, USD for USA…)
- **Biometrics** — `required: true` only for Canada, UK, USA, Schengen, Australia; optional elsewhere

### Save & share progress (serverless)
No account or backend required. Progress is encoded as a URL hash:

```
https://visaprep.app/#s=BASE64
```

The "Sign in" button in the top bar opens the **Save modal** which:
- Shows the shareable URL (read-only input)
- Copy link button — writes to clipboard
- Email to myself link — opens `mailto:` with the URL in the body

Opening the URL on any device restores country, current step, profile selections, and all document statuses. The hash is cleared from the URL after restore so bookmarks stay clean.

### Navigation pages
Four nav links in the top bar now route between views (no page reload, no React Router — Zustand `page` state):

| Page | Path | Content |
|------|------|---------|
| Application | default | The checklist app |
| Guides | `/guides` | How-to articles (stub — 3 cards) |
| Documents | `/documents` | Document type reference (stub — 8 cards) |
| Help | `/help` | FAQ accordion (6 questions) |

Stub pages have the full layout shell; content will be filled in a future release.

### Key implementation notes

- `getDocsForCountry(countryKey)` returns a fresh deep-cloned array per call — safe to mutate, no shared state between renders
- `BIOMETRIC_COUNTRIES = new Set(['canada', 'uk', 'usa', 'schengen', 'australia'])` — single source of truth for biometrics requirement
- URL hash format: `#s=btoa(JSON.stringify({ statuses, current, profile, country }))` — no server, no auth, works offline
- Page routing via `page` field in Zustand store (`'app' | 'guides' | 'documents' | 'help'`); keyboard nav guards on `page === 'app'`
- CSS convention: `var(--line)` for borders (not `var(--border)`, which is not defined in tokens.css)
